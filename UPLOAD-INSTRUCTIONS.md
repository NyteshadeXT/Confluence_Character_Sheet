# Initial GitHub Upload

Repository:

`https://github.com/NyteshadeXT/Confluence_Character_Sheet`

## Recommended: GitHub Desktop

1. Unzip this package.
2. In GitHub Desktop, clone `NyteshadeXT/Confluence_Character_Sheet`.
3. Copy the **contents** of the `Confluence_Character_Sheet` folder into the cloned
   repository folder.
4. Commit with a message such as:
   `Initial Hosted Connected Prototype v0.4`
5. Push `main`.

Do not commit the ZIP itself as the application source.

Once pushed, import/connect that repository in Vercel. The Vercel project root should
remain the repository root; no build command is necessary.
