# v0.4.10.6.3 — GM Remove Training UI Fix

Campaign Management now exposes a clearly labeled GM-only **Remove Skill / Weapon Training** control.

- Lists Skill and Weapon Skill entries only.
- Prioritizes currently trained entries.
- Resets the selected entry to Untrained / Rank 0.
- XP is not refunded.
- Uses the GM-protected backend RPC introduced in v0.4.10.6.2.
