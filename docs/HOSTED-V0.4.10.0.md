# v0.4.10.0 — Power Resolution & Advancement

- Power editor now supports Source Essence, Fixed Ability, or Permanent Player Choice.
- Allowed permanent attack ability choices are configured in System Data Studio.
- Defense Targeted is a structured field (AC, Fortitude, Reflex, Will).
- Player makes a permanent attack-ability choice when a choice Power is acquired.
- The chosen ability drives Power Attack and chosen-ability modifier text.
- Rank builder adds Modify Existing Effect Value and Enhance Existing Effect.
- Appended Rank riders display with the milestone name.
- No database schema migration required.
