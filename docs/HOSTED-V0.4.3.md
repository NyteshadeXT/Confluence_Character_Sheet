# Hosted Connected Prototype v0.4.3 — Player Character Creation

Players added to a campaign by the GM can now create one or more characters from the Character Portal. New characters automatically belong to the signed-in player. The existing GM-created/unclaimed character workflow remains available.

Initial creation collects Name, Ancestry, and STR/DEX/CON/INT/WIS/CHA. The backend starts the character at 0 XP, 10 HP, 0 Mana, 0 Stamina, 0 Healing Surges, with empty Training, Equipment, Loadout, Essences, and Powers.
